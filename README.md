# 江湖小伴 · Windows 桌宠

本仓库提供 Windows 压缩版安装包及更新说明。

## 下载与安装

前往 [最新发行版](https://github.com/ianfog/jx3-pet-releases/releases/latest)，下载 `JX3PetDemo-Compact-Setup.exe` 后运行。

首次安装或从 v0.4.11 及更早版本升级，需要手动运行一次安装包。从 v0.4.12 起，可在桌宠右键菜单或角色设置中打开“关于与更新”，检查、下载并安装新版。

升级保留本机角色、备注和任务记录。更新需要联网；桌宠日常使用仍可离线。

请使用本仓库发行版附件中的安装程序；GitHub 自动生成的 Source code 压缩包不包含桌宠程序。

## 说明

江湖小伴为非官方同人桌宠，角色素材为 AI 生成的同人改绘。本仓库仅用于发布安装包和版本信息。
